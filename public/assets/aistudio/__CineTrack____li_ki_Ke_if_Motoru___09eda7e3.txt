## 🆕 Yeni Eklenenlerin Değerlendirmesi

### Gerçekten İyi Yapılmışlar 👏

1. **Sunucu cache katmanı (commit `8a1f2f6` + `eef035f`)**: Endpoint bazlı TTL (trend 10dk, keşif 15dk, detay 1sa, oyuncu filmografisi 2sa), **single-flight istek dedup** (aynı istek uçarken ikinci istemciyi bekletme), upstream hatasında **stale-cache fallback** ve dürüst hata (önbellek yoksa demo uydurma yerine 502). `X-CineTrack-Source` header'ları + istemcide pub/sub ile durum takibi (`/api/tmdb-status`) — bu, profesyonel API tasarımı.
2. **İlişki Keşfi (relationship-explorer)**: Kanıt-öncelikli yaklaşım — "bu sürüm LLM/embedding kullanmaz" diye açıkça söyleyip koleksiyon ID → ortak kadro → özet/tür benzerliği (Jaccard) hiyerarşisi, her ilişki için **kanıt listesi + güven skoru**. Jenerik kelimelerle yapay ilişki üretmemesi test edilmemiş (15 kaliteli test). İmza bazlı cache invalidation (FNV-1a stable hash) doğru mühendislik.
3. **IndexedDB'ye geçiş**: İlişki grafikleri localStorage yerine IndexedDB'de — kota bilinci önceki önerimle uyumlu ve doğru karar.
4. **UX ayrıntıları**: Önbellek bildirimleri dürüst ("Kullanıcı listesi değişmiş. Haritayı güncelle"), boş durumlar hedefe özel aksiyonlarla ("İlk Kaynağı Seç", "Filtreleri Sıfırla"), lejant, kanıt listeleri. Kanıt gösterimi bu özelliğin ürün değerini gerçekten artırıyor.

### Yeni Bulgular 🔍

**🔴 Kritik — Yeni bulgu:** `.gitignore` yalnızca `.env.local` ve `data/` içeriyor. **`.env` ve `node_modules` yok!** README `cp .env.example .env` yapıp TMDB anahtarını oraya koymayı söylüyor — bir `git add .` ile **API anahtarınız repoya sızar**. Ayrıca `node_modules` klasörü committable durumda.

**🔴 Kritik — Hâlâ duruyor:** Express 5 `app.get('*')`. Production build'i (`npm run build` + `NODE_ENV=production`) açılışta `path-to-regexp` hatasıyla çöker. Muhtemelen hiç production modunda test edilmedi.

**🟠 Yüksek:** `react-force-graph-2d` **statik import** ediliyor (App → RelationshipExplorer). d3-force + canvas motoru ana bundle'a giriyor; kullanıcı İlişki Keşfi sekmesini hiç açmasa bile ~200KB+ ek yük. `React.lazy` + `Suspense` ile tab-bazlı kod bölme şart.

**🟠 Yüksek:** Algoritma sürüm enflasyonu: artık v1 motor + v3 + **v3.2.0 (priority scores)** + relationship-v2 aynı anda yaşıyor ve App hepsini import ediyor. Bu, öneri davranışını hem belirsizleştiriyor hem test yüzeyini ikiye katlıyor.

**🟡 Orta (UX):**
- **Graf erişilemezliği**: Canvas tabanlı force graph klavye ve ekran okuyucu için tamamen kapalı. Düğüm seçimi yalnızca fare tıklamasıyla; `aria-live` ile seçili düğüm bilgisi duyurulmuyor. Sağ paneldeki veriyi bir "liste görünümü" alternatifiyle sunmak hem a11y hem düşük donanım için kurtarıcı olur (Zevk Haritası'nda `graph | list` mode state'i zaten var — bunu relationships'e de taşıyın).
- Kaynak yapım dropdown'ı yüzlerce öğeyle büyüyebilir; aranabilir bir seçim (combobox) ileride gerekli.
- Emoji ikon dili büyümeye devam ediyor (🗺️ ◉ 🔬 🎯) — SVG sprite ile karışım sürüyor.

## 🗺️ Düzeltme / İyileştirme Planı

### Sprint 1 — Güvenlik ve Kırılanlar (yarım gün, %100 yapılmalı)

1. **`.gitignore`'ı düzelt** — şu satırları ekle:
   ```
   .env
   .env.*
   node_modules/
   dist/
   ```
   `.env` hiçbir zaman repoya girmemeli. (Anahtar sızdıysa TMDB'den yenileyin.)
2. **Express 5 route'unu düzelt** — `server.ts`:
   ```ts
   app.use((req, res, next) => {
     if (req.method !== 'GET' || req.path.startsWith('/api/')) return next();
     res.sendFile(path.join(distPath, 'index.html'));
   });
   ```
   Sonra `NODE_ENV=production npm start` ile **bir kez gerçekten test edin.**
3. **`vite.config.ts`'ten `allowedHosts: true`'yu kaldır**, `host`'u `127.0.0.1` yapın (LAN istenirse `CINETRACK_HOST=0.0.0.0` zaten server.ts'te var — Vite'a gerek yok).
4. **`index.html`'den `<link href="/style.css">` satırını sil** (prod'da 404, dev'de çift yükleme).

### Sprint 2 — Performans ve Ölü Kod (1 gün)

5. **`App.tsx` render içi `JSON.stringify`'ı düzelt**: snapshot'ı `useMemo([...bağımlılıklar])` ile hesaplayın ya da daha iyisi: her write'ı gerçekten yapan bir "dirty" flag'i kaldırıp, effect'i yalnızca `savedItems/preferences/profiles` referans değişiminde çalıştırın.
6. **Ölü v1 motorunu silin**: `buildTasteProfile`, `scoreCandidates`, `diversifyList`, `createCandidatePool` artık kullanılmıyorsa core'dan export listesinden çıkarın (kullanılıyorsa v3'e migrate edin — iki motor aynı havuzu puanlıyorsa davranış belirsiz).
7. **`React.lazy` ile kod bölme**:
   ```tsx
   const RelationshipExplorer = React.lazy(() => import('./components/RelationshipExplorer'));
   const TasteMapView = React.lazy(() => import('./components/TasteMapView'));
   // <Suspense fallback={<Spinner/>}> ile tab içeriğini sarın
   ```
8. **Tek paket yöneticisi seçin**: `bun.lock` gitmiş ama geri gelmiş. Ya npm + `package-lock.json` + tsx'e geçin ya da tümünü bun'a taşıyın. `start.bat`'ın `--no-package-lock` kurulumu da aynı karara bağlansın.

### Sprint 3 — UX Dürüstlüğü ve Erişilebilirlik (1–2 gün)

9. **%82 fallback'i kaldırın**: `matchScore` yoksa rozeti hiç göstermeyin ya da "Öneri" gibi dürüst bir etiket koyun. Zevk haritasında zaten `tasteScore` var — aynı dürüstlük kartlara da taşınmalı.
10. **Typeahead'e klavye navigasyonu**: `role="combobox"` + `aria-expanded` + ↓/↑ ile aktif seçenek + Enter ile seçim. (~80 satır, mevcut requestId altyapısıyla uyumlu.)
11. **Dev panelini kaldırın** ya da `import.meta.env.DEV &&` arkasına alın.
12. **Graf için liste alternatifi + aria**: Seçili düğüm bilgisi `aria-live` bölgesine yazılsın; "Liste görünümü" modu İlişki Keşfi'ne de eklensin; reduced-motion için `@media (prefers-reduced-motion: reduce) { * { transition: none !important; animation: none !important } }` ve force graph'ta `cooldownTicks` azaltma.

### Sprint 4 — Altyapı (1 gün)

13. **ESLint (typescript-eslint + react-hooks + a11y) + Prettier** kurun — kodda zaten `eslint-disable` yorumları yazıyorsunuz, kural seti olmasınca bunlar sadece dekorasyon. `lint` script'i `eslint . && tsc --noEmit` olsun.
14. **GitHub Actions CI**: `push`'ta `npm ci && npm run lint && npm test && npm run build` + **production modunda sunucunun ayağa kalktığını doğrulayan tek bir smoke testi** (Sprint 1'deki hatayı bir daha kimse görmesin diye).
15. **LICENSE ekleyin** (repo public ama lisanssız — kimse kullanamaz, siz de korumasızsınız).
16. **TMDB tip tanımları**: `src/types/tmdb.ts` ile `TmdbItem`, `TmdbListResponse`, `TmdbCredits`… Yeni `relationship-explorer.ts` bunu zaten gösteriyor (0 `any`!) — aynı standardı eski koda taşıyın.

### Sonrası — Ürün (Sprint 5+)

17. Liste sanallaştırma (react-window) ya da "Listem" için sayfalama — 5000 öğe sınırına doğru büyüyen risk.
18. i18n katmanı (metinler artık 3 bileşen katmanına dağıldı; her geçen gün pahalılaşıyor).
19. Provider verisini tek kaynağa bağlayın (TMDB `/watch/providers` yanıtından beslenen config; 410/119 tutarsızlıkları bitsin).
20. Zevk haritası arşivleme özelliğinde ilerlemiş görünüyorsunuz (`markTasteMapItemStatus`, entry archiving) — bu iyi bir yön; öneri motoru sürümlerini (v1/v3/v3.2.0) tek bir `engineVersion` sabitinde birleştirip veri şemasına gömün, böylece cache'ler ve testler tek.truth source'a bağlanır.
